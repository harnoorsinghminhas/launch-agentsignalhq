## Logo artwork

`assets/logo.svg` are drawn from **Figtree SemiBold** (SIL OFL 1.1, https://github.com/erikdkennedy/figtree). The letters were converted to outlines, so no font file is shipped.

## System fonts

The CSS lists system fonts (for example Segoe UI, Georgia or Impact) only as fallbacks. They are drawn by the visitor's own device;
this site does not ship or embed them.
